# NVPLUSH — English Christmas website

Open `index.html` directly in a browser. The published page loads its CSS, JavaScript and image assets through jsDelivr.

## September 2026 redesign
- English throughout: navigation, product copy, accessible labels, dialogs, form, notifications and downloaded enquiry files.
- Burgundy, warm ivory and evergreen visual direction; large editorial serif typography.
- All seven original product groups retained, with four single-page navigation anchors.
- Native-ratio, edge-to-edge photography: no coloured frames, mixed background overlays or cropped products. Editorial masonry adapts to each source photograph.
- All UI and decorative icons use Hugeicons free stroke icons, on transparent backgrounds. Saved state remains outlined with colour and a small state dot; no mixed icon styles.
- Wishlist, filters, penguin gallery, product-to-enquiry selection and local enquiry download remain available.
- The hero keeps its original contained product layout. Supplied reference backgrounds are reserved for the holiday and contact feature sections, with neutral content sections between them.
- The layout follows a reusable Webflow-style rhythm: full-width sections, constrained content, consistent spacing and responsive desktop/tablet/mobile breakpoints.

## Icons
Source: https://hugeicons.com/ and the official `@hugeicons/core-free-icons` package, version 4.3.2 (MIT). `hugeicons.js` contains only the eleven icons used by this site, bundled locally. https://github.com/hugeicons/hugeicons

## Before publishing
Confirm brand copy, official contact details, product specifications and purchase links. The enquiry form downloads a file and does not submit online. No pricing, certification, charity or sales claims have been invented.

## Files
`index.html`, `styles.css`, `app.js`, `hugeicons.js`, and `assets/`.
The earlier version is preserved in `../_design-source/v1/`.

## Squarespace embed
Paste the contents of `squarespace-embed.html` into a Squarespace Code Block. The standalone HTML uses raw.githack and loads images, CSS and JavaScript through jsDelivr.
