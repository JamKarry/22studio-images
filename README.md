# 22STUDIO image assets

Public image assets used by the exported standalone HTML pages.

Raw URL base:

```text
https://raw.githubusercontent.com/JamKarry/22studio-images/main
```

Example:

```text
https://raw.githubusercontent.com/JamKarry/22studio-images/main/22studio/gifts/hero.jpg
```

The standalone HTML keeps CSS and JavaScript inline. This repository is only
used for publicly accessible image URLs.
